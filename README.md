# 📚 Book Tracker (Трекер прочитанных книг)

**Автор:** [Малинин Анатолий]  
**Дата создания:** 25.04.2026

## 📝 Описание
Приложение для управления списком прочитанных книг с графическим интерфейсом. Позволяет структурировано хранить данные о вашей библиотеке, фильтровать книги по критериям и автоматически сохранять прогресс в локальный файл.

## ✨ Возможности
*   **Удобная форма ввода:** добавление названия, автора, жанра и количества страниц.
*   **Умная фильтрация:** поиск по жанру и быстрый отбор книг объемом более 200 страниц.
*   **Надежное хранение:** автоматическое сохранение и загрузка данных из формата `JSON`.
*   **Валидация:** проверка на пустые поля и корректность ввода чисел.

## 🚀 Установка и запуск

### Требования
*   **Python 3.8** или выше.
*   Стандартные библиотеки Python: `tkinter`, `json`, `os`.

### Запуск программы
1.  **Склонируйте репозиторий:**
    ```bash
    git clone <ссылка_на_ваш_репозиторий>
    ```
2.  **Перейдите в папку с проектом:**
    ```bash
    cd book-tracker
    ```
3.  **Запустите основной файл:**
    ```bash
    python main.py
    ```

## 🛠 Технологии в проекте
*   **Tkinter** — создание графического интерфейса пользователя (GUI).
*   **JSON** — хранение базы данных в текстовом формате.
*   **Git/GitHub** — контроль версий и размещение кода.
